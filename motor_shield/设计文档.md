# MOC-Motor 扩展板设计方案 v1.0

> 目标：为 ESP32-S3 MOC 2.0 开发板设计**电机驱动扩展板（Shield）**，叠插即用
> 日期：2026-09-25 · 状态：设计完成，待布局打样
> 交付物：本设计文档 + KiCad 网表（立创EDA 专业版 / KiCad 均可导入）

## 一、需求与设计假设

| 项 | 设计值 | 说明 |
|----|--------|------|
| DC 有刷电机 | **2 路**（TB6612FNG，每路 1.2A 持续 / 3.2A 峰值） | 可做二轮差速小车 |
| 舵机 | **3 路**（SG90/MG90S 级别，独立 5V 大电流轨） | 机械臂/云台 |
| 步进电机 | **1 路**（A4988 插座，可选焊装） | 42/28 步进电机 |
| 电机电源 | 外部 6–12V（DC005 插座 + XT30 焊盘双输入） | 与主板 USB 隔离 |
| 逻辑电源 | 从主板排针取 3.3V | TB6612 逻辑侧 |
| 形态 | 叠插 Shield（2×17 双排母对接主板排针） | 板寸 ~60×60mm |

## 二、引脚分配（本板实测档案 + esp-claw 固件占用全核查）

### 已排除（不可用/已占用）

- 硬禁：GPIO19/20（USB）、26–32（Flash）、35–37（PSRAM）、43/44（UART0 console）
- esp-claw 固件已初始化：2/3(I2C)、4/5(SPI)、9(I2S)、16(LEDC)、48(WS2812)
- 套件教学占用：0(BOOT)、1、6、7、8、10、11、12、13、17、18

### 分配表（空闲 9 脚 + 电机类复用 3 脚）

| 扩展板功能 | 信号 | GPIO | 备注 |
|-----------|------|------|------|
| **TB6612 电机A** | AIN1（方向1） | **GPIO42** | 下排空闲 |
| | AIN2（方向2） | **GPIO41** | 下排空闲 |
| | PWMA（调速） | **GPIO40** | LEDC 硬件 PWM |
| **TB6612 电机B** | BIN1 | **GPIO39** | 下排空闲 |
| | BIN2 | **GPIO38** | 下排空闲 |
| | PWMB（调速） | **GPIO21** | LEDC 硬件 PWM |
| TB6612 待机 | STBY | **GPIO47** | 高电平使能；10K 上拉到 3.3V，上电即安全待机 |
| **A4988 步进** | STEP | **GPIO45** | strapping 脚，**10K 下拉**（确保上电期间不跳步） |
| | DIR | **GPIO46** | strapping 脚，**10K 下拉** |
| **舵机×3** | SIG1 | **GPIO14** | 套件标准舵机位（不冲突） |
| | SIG2 | GPIO15 | 与 DS18B20 复用（接舵机时拔温度计） |
| | SIG3 | GPIO17 | 与 L9110 风扇复用（二选一） |

> 设计原则：**所有控制脚都带确定电平的上下拉**——上电瞬间到固件初始化完成之前，电机保持静止（TB6612 IN 脚 100K 下拉，A4988 STEP/DIR 10K 下拉）。

## 三、电源架构

```
外部电源 6–12V ──┬── DC005 插座（J1）
                └── XT30 焊盘（J2，并联，接电池）
        │
   [反接保护] AO3401 P-MOS（Q1，压降≈0）
        │ VM 轨（=电机电源）────── TB6612 VM ── 100uF/25V 钽电容 ── A4988 VM
        │                              └─ 5A 自恢复保险丝
        └──[MP1584EN 降压]── 5V/3A 轨 ── 舵机×3 ── 1000uF/16V 电解（浪涌）
                │                    └─ 3A 自恢复保险丝
                └──（5V 轨不回灌主板：主板 5V 与扩展板 5V 用肖特基隔离或完全独立）

主板 3.3V（经排母）── TB6612 VCC / A4988 VDD（逻辑）
GND：主板 GND ↔ 扩展板 GND ↔ 电机电源 GND **必须共地**
```

要点：
1. **共地是铁律**——功率地与信号地在扩展板上单点汇接（星形）
2. 舵机 1000uF 储能电容：SG90 堵转启动浪涌 ~0.7A×3，没有大电容会把 5V 轨拉塌导致主板复位
3. 反接保护用 P-MOS 而非二极管：电机电流下二极管 0.7V×3A=2W 发热不可接受，MOS 毫欧级
4. 主板 USB 5V 与扩展板 5V **不并联**（防倒灌烧 USB 口）

## 六、软件对接（esp-claw / MicroPython 已验证的路径）

- esp-claw：Lua 模块可操作 GPIO/LEDC（`lua_module_gpio`、RMT 等 27 个模块已注册）
- MicroPython：`machine.Pin` + `machine.PWM`（LEDC 底层）直接驱动
- 示例（MicroPython 双电机差速）：

```python
from machine import Pin, PWM
ain1, ain2 = Pin(42, Pin.OUT), Pin(41, Pin.OUT)
pwma = PWM(Pin(40), freq=20000, duty_u16=0)   # 20kHz 无声调速
bin1, bin2 = Pin(39, Pin.OUT), Pin(38, Pin.OUT)
pwmb = PWM(Pin(21), freq=20000, duty_u16=0)
Pin(47, Pin.OUT, value=1)                     # STBY 拉高使能

def motor(pwm, in1, in2, speed):  # speed: -100..100
    if speed > 0:   in1(1); in2(0)
    elif speed < 0: in1(0); in2(1)
    else:           in1(0); in2(0)
    pwm.duty_u16(abs(speed) * 655)

motor(pwma, ain1, ain2, 60)   # 电机A 60% 正转
motor(pwmb, bin1, bin2, -60)  # 电机B 60% 反转 → 原地转
```
