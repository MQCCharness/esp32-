# 需求梳理：把「折叠开合」视觉特效移植到直板机

## 一、一句话需求

在**直板机**上用**陀螺仪倾斜**模拟苹果折叠屏「开合」时的视觉特效：界面内容表现为一块**有惯性的虚拟平面**，
跟随手机倾斜但**滞后**，滞后造成的**不平行**产生 3D 透视与**越远越模糊**的效果，最终缓慢收敛回与屏幕平行（清晰）。

## 二、效果拆解（用户原话 → 技术规格）

| 用户描述 | 技术规格 |
|---------|---------|
| 「不是横纵翻转，是左倾右倾」 | 取手机**绕自身 Y 轴（长轴）的 roll**，即把手机左右边缘朝自己/朝外翻转（即折叠屏铰链的开合轴）；**不是**横竖屏切换 |
| 「平的时候是清晰的」 | 虚拟平面与物理屏幕**平行**时 → 模糊半径 = 0 |
| 「界面会有类似开折叠的模糊特效」 | 不平行量 → 驱动模糊强度 |
| 「页面的 UI 依然是原来那个（角度也会随手机动）」 | **UI 内容本身不重排、不旋转**（不加倍跟随），只做整体平面变换 |
| 「有延迟，慢慢翻转直到和手机屏幕平行」 | 虚拟平面角度对真实角度做**指数滞后**（一阶惯性），时间常数可调；静止后自动收敛到平行 |
| 「不平行的部分偏离屏幕越远越模糊」 | **梯度模糊**：按 3D 深度（与屏幕平面的距离）加权，深度越大越糊；只有后退的一侧糊，前进的一侧保持清晰 |

## 三、核心算法

```
传感器 Game Rotation Vector (type 15, 无磁力计干扰)
        ↓  四元数 q_device（设备→世界）
虚拟平面对齐（指数滞后 / slerp-nlerp）
        q_virtual ← nlerp(q_virtual, q_device, 1 − e^(−dt/τ))
        ↓
不平行量（设备坐标系下的相对旋转）
        q_err = conj(q_device) · q_virtual
        ↓  轴角分解 (θ, axis)
    ┌───────────────┴───────────────┐
rotationY = θ · axis.y          blur ∝ |θ|
（3D 透视倾斜）                  （按深度加权，取后退侧）
```

- **滞后时间常数 τ** 可调：τ 越大越"重"，收敛越慢
- **静止收敛**：q_virtual 持续趋近 q_device → θ → 0 → 画面回到完全清晰
- **凹凸不敏感**：用 Game Rotation Vector 而非 Rotation Vector，避免磁力计抖动

## 四、渲染实现

1. **3D 透视**：`Modifier.graphicsLayer { rotationY / rotationX / rotationZ; cameraDistance }`
2. **梯度模糊**：`RuntimeShader` (AGSL, API 33+) 通过 `RenderEffect.createRuntimeShaderEffect` 注入
   - 采样权重按 `t = clamp(normalizedX · tilt, 0, 1)` 变化 → 后退侧模糊、前进侧清晰
   - **降级**：API < 33 时退回 `Modifier.blur()` 均匀模糊

## 五、关键设计决策（含一处歧义的处理）

**歧义点：倾斜轴**

「左倾右倾」有两种解读：
- **(A) 绕长轴 roll**（手机左右边缘朝自己/朝外翻）→ 内容呈 3D「开门」透视，**一侧深一侧浅 → 有梯度模糊**
- **(B) 绕屏幕法线 in-plane**（像打方向盘一样转）→ 内容只是平面内旋转，**没有深度差 → 无梯度模糊**

用户明确要求「不平行的部分偏离屏幕越远越模糊」，**只有 (A) 能产生深度差**，
且 (A) 正好是折叠屏铰链的开合轴。**因此默认取 (A)**。
同时 App 内提供 **轴模式切换**（Y轴 / X轴 / Z轴 / 全轴），用户可现场对比确认。

**其他默认值**（App 内均可实时调节）：
- 滞后时间常数 τ = 450 ms
- 倾斜增益（视觉放大倍数）= 1.2×
- 最大模糊半径 = 18 px（按屏幕密度换算）
- 最大旋转角 = 25°（防快速甩动时画面破坏）

## 六、验收方式

1. 界面提供一个**手动模拟滑块**（覆盖传感器输入）——可不开传感器就直接看到效果
2. 实时数值面板：真实角度 / 虚拟角度 / 不平行量 / 当前模糊半径
3. 参数面板：τ、增益、模糊强度、轴模式 全部可调
4. 用 adb 驱动滑块 → 多档截图 → 逐档核对「左倾糊左侧 / 右倾糊右侧 / 平了全清晰」

## 七、交付物

- 一个可直接安装到小米 Mi 10 的 APK
- 特效封装为**单个 Compose Modifier**，用户可原样套到自己 App 的内容外面
- 参数可调面板（帮用户找到他想要的"手感"）
